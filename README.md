# digital-loop-switcher-de-5-canais-para-guitarra.-
Este é um projeto para Arduino que finalizei há uns 2 anos, mas estou refazendo para ficar mais compacto, com menos peças. 

Este projeto utiliza:
          1 Arduino Mega 256 Pro
          1 i2c 8bits PCF8574 (originalmente eu utilizava 2)
          1 banco de relés  8 canais (mas não utilizo todos, apenas 6)
          1 display oled RGB de 1,5 polegadas
          1 encoder clicável
          1 led RGB
          5 leds (da cor que desejar =])
          6 a 8 chaves SPST para pedais (vou inserir nas fotos)
          6 resistores (utilizei os de 220R)
          Vários fios coloridos =]

Este projeto ainda está na mesa de testes, e as fotos que tenho são do projeto antigo.
